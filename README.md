# TALKSSOGI (톡쏙이)
카카오톡 단체 채팅방 대화를 분석해 사용자 맞춤형 피드백과 시각화를 제공하는 앱/웹



## 개요
- **목표**: 카카오톡 단체 채팅방의 대화 내용을 분석해 **사용자 맞춤형 피드백**을 제공하고, 커뮤니케이션 효율성 향상을 돕는 애플리케이션
- **입력**: 카카오톡의 **대화 내보내기 기능**으로 얻은 텍스트 파일을 **업로드**
- **산출**: 대화 패턴, 주요 단어, 활동 시간대 등 **분석 및 시각화 결과**
- **효과**: 사용자가 자신의 대화 습관을 인지·개선할 수 있도록 **객관적 자료** 제공
- **UI**: 웹페이지와 안드로이드 앱 화면 제공

## 시스템 구조 / 적용 기술
- **서버**: Spring Boot (AWS EC2에서 실행)
  - **저장소**: **RDS**(데이터베이스), **S3**(이미지/파일)
- **데이터 분석**: **TensorFlow**, **pandas**, **NumPy**를 활용하여 채팅방 데이터 분석
- **클라이언트**
  - **Android**: **Kotlin**으로 앱 제작 (Android Studio)
  - **Web**: **Spring Boot + Thymeleaf** 기반 동적 웹페이지

## 주요 기능 

### 1) 워드 클라우드
- **설명**: 채팅방의 **주요 단어를 시각화**하여 한눈에 파악
- **세부**: 형태소 분석 후 **빈도수 측정**을 바탕으로 워드 클라우드 이미지 생성

### 2) 랭킹 분석
- **설명**: **주제별 사용자 순위** 제공
- **예시 주제**:  
  - 가장 **메시지를 많이 보낸** 사람  
  - 가장 **사진을 많이 보낸** 사람  
  - 가장 **오타가 많은** 사람  
  - 가장 **메시지를 많이 삭제한** 사람  
  - **특정 단어** 사용 순위(**검색** 기반)

### 3) 활동 분석
- **설명**: 대화 **활동 추이/분포** 분석 
- **예시 지표**:  
  - **메시지 수가 가장 많았던 날**  
  - **대화를 하지 않은 날**  
  - 평균적으로 **가장 활발한 시간대**  
- **맞춤 분석**: 날짜/사용자/결과 유형 선택 후 결과 확인

### 4) 발신자 예측
- **설명**: 특정 **단어 또는 문장을 누가 보냈을지** 예측
- **특징**: 같은 의미라도 **말투 분석**을 반영해 가능성이 높은 발신자를 제시

### 5) 회원/세션 관련
- **회원가입/로그인**: 아이디 **중복 검사**, 자동 로그인(마지막 로그인 계정), **로그아웃**
- **데이터 유지**: 업로드한 채팅방 데이터는 **아이디별로 유지**
- **채팅방 업데이트**: 기존 분석 후 **추가된 대화 내용**을 **업데이트 반영**



## 발신자 예측 모델 구조 

### 학습 데이터/임베딩
- **발신자 67명**에 대해, 발신자별 메시지를 바탕으로 **임베딩 벡터(48차원 실수)** 구성

### 1단계: `Caller_prediction1.py`
- 문장 임베딩: **BERT 마지막 층 평균**으로 문장 임베딩 벡터 생성
- **MLP 모델**로 사전 학습 → **발신자 임베딩 벡터**로 매핑
- **67명**에 대해 **새로운 발신자 매핑** 생성 후 **DB 저장**

### 2단계: `Caller_prediction2.py`
- 입력: **예측할 문장**
- **LSTM 모델**로 사전 학습
- DB의 매핑 결과를 읽어 **새로운 채팅방 발신자 중 한 명**으로 치환·출력 (이름 출력)
